## 约定流程

1. 按论文价值排序依次阅读。
2. 助手介绍研究问题、方法、实验、比赛用途和局限。
3. 用户提问，逐项讨论；可以随时补充问题。
4. 用户表示本篇提问结束后，将要点、用户问题、回答与修正整理为本目录的 Markdown 文件；单篇若另有归档要求，以用户当次要求为准。
5. 明确区分作者报告的结果、讨论中的判断和已经实际验证的结论。完成归档不代表已复现论文。
