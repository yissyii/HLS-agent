# 自建测试 v0.2 第一包交付：有界采样＋独立判据审核

日期：2026-09-23。范围：独立实验模块；未接入主 Agent、RAG、比赛入口或自动修复。

## 本次完成

1. 有界采样 `--planning-policy bounded-v2`：程序根据声明输入域和预算选择穷举或边界＋随机；保留原模型计划、实际计划和调整理由。显式用例不能被静默丢弃。
2. 布尔格式规范化：只对 bool 参数接受 true/false 并转换为 1/0，其他参数继续严格检查。错误消息区分类型不符与数值越界。
3. 新增独立 `audit` 命令：读取冻结测试包、明确的规则绑定或外部锚点，给出 supported/conflict/inconclusive；不读取候选代码、不请求模型、不修改测试包。
4. 首批三条规则：Gray 解码、位反转、置位计数；结合独立算法、锚点及补充性质检查。输入限制为单个无符号参数、完整 1～16 位输入域。
5. 保持旧包兼容、默认 strict 行为；有界策略使用新 schema 并冻结额外证据。评测 freeze 命令也可显式冻结该策略。
6. 新增旧响应回放工具与回归测试，保留历史实验原件。

**规则库是本次开发编写并经算法对照回归的原型，尚未经过其他队员独立人工审核。规则和任务之间的语义匹配也未自动证明。本版不输出“已证明符合题意”。**

调用者在已知旧结果后，显式选择了以下规则绑定；这是已见案例回归，不能作为规则自动选择准确率。

| 原模型测试包 | 审核结果 | 范围与说明 |
| --- | --- | --- |
| count_bits8 | supported | 256 个输入，对照与补充性质无冲突 |
| reverse_bits8 | supported | 256 个输入，对照与补充性质无冲突 |
| gray_decode8 | conflict | 256 个输入中 254 个与选定规则不一致 |

Gray 的首个反例：输入 1，规则答案为 1，模型原判据算出 0。这里的 actual 指原判据计算值，不是候选代码输出。
审核只生成旁路报告，不会阻止已有 run 命令，也不会自动修改候选；接入决策尚未实施。
报告位于 `output/selftest_v02_replay_native_20260923/audits/`。
