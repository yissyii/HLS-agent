日期：2026-09-16。

> 本文记录首版实现时的测试数量与耗时，不代表每次文档更新均重新运行了测试。后续源码提取、研发会话管理、真实模型评测与 RAG 进展见 [当前状态](instruction.md) 和 [报告索引](../README.md)。

## 已实现

按 [Agent 设计文档](design.md) 的七个功能目录实现了独立入口、公共类型、控制器、策略、上下文构造、诊断、候选管理、证据写入及可选只读技能检索。

- 默认一次生成、最多两次修复；功能和综合验证通过后停止。
- 支持仅题目模式、公开测试清单模式，以及无测试台时的单独综合。
- 旧 `run_eval.ps1` 经 `evaluation/single_task.py` 调用相同控制器，保留“验证通过才退出 0”的语义；新 agent 入口退出 0 表示候选交付成功。
- `run_paired.sh`/`serve.paired_entry` 运行独立 baseline 与 agent，冻结输入、配置、策略与启用的技能包，校验回执及材料哈希。
- 子进程限时、重复候选停止、错误停滞停止、基础设施错误停止、修复后重新验证，以及退步时选择证据更好的旧候选。
- 每个候选拥有独立 HLS 工作目录，验证证据绑定源码、任务与工具配置哈希。
- 提供 `run_agent.ps1`，Windows 标准配对入口可直接使用 Python，无需 Bash。

## 实际 Vitis 验证

命令：`python -B tools/smoke_agent_hls.py --config serve/runtime.local.json`。

使用新写的 `kernel(a) = a + 1` 算术题，测试台遍历 `[-100, 100]`。本机 HTTP 模拟服务第一次返回含未定义变量的代码，第二次返回正确代码。执行的 Vitis 为本机 2025.2，器件 `xczu3eg-sbva484-1-e`、时钟约束 5 ns。

| 环节 | 结果 |

| 初始候选 csim | 编译失败，进入有限修复 |
| 修复候选 csim | 通过 |
| 修复候选 csynth | 通过，生成综合 XML 和 RTL |
| 最终候选 | 1 号候选，四项检查通过 |
| 模拟模型请求 / HLS 调用 | 2 / 3 |
| 总时间 | 83.076 秒 |
| HLS 综合估计 | 时钟 1.203 ns，LUT 39，FF/DSP/BRAM 为 0 |

证据目录：[实际运行记录](F:/Projects/ADMCmpt/zcomp/output/agent_hls_smoke_20260916T052942150809Z/agent/result.json)。同级 `fixture.json` 保存模拟请求并明确标记 `mock_model=true`、`real_vitis=true`。
